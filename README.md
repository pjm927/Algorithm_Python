# Python Algorithm Study

정보올림피아드 준비를 위해 다양한 알고리즘을 Python으로 직접 구현하고 정리하는 저장소입니다.

알고리즘의 동작 원리를 이해하고, 문제 해결 과정에서 직접 활용할 수 있도록 학습한 내용을 코드로 작성하여 기록합니다.

## Contents

* Basic Algorithms
* Sorting
* Searching
* Brute Force

* Dynamic Programming
* Graph
* Data Structure
* Number Theory
* String Algorithm
