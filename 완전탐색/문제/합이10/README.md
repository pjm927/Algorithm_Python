
# 합이 10이 되는 두 수 찾기

## 문제

1부터 10까지의 숫자 중 두 수를 골라 **합이 10이 되는 모든 경우**를 찾는다.

---

## 방법 1: 완전탐색 (Brute Force)

두 개의 반복문을 사용하여 가능한 모든 `(i, j)` 조합을 확인한다.

```python
for i in range(1, 11):
    for j in range(1, 11):
        if i + j == 10:
            print(i, j)
```

### 동작 방식

* `i`를 1부터 10까지 반복
* 각각의 `i`에 대해 `j`도 1부터 10까지 반복
* `i + j == 10`인지 모든 경우를 확인
* 조건을 만족하면 두 수를 출력

### 시간 복잡도

**O(N²)**

두 개의 반복문을 중첩하여 모든 조합을 확인하기 때문이다.

---

## 방법 2: 관계식 이용

`i + j = 10`이라는 조건을 이용하면 `j`를 직접 계산할 수 있다.

> `j = 10 - i`

따라서 모든 `j`를 하나씩 확인할 필요가 없다.

```python
for i in range(1, 10):
    j = 10 - i
    print(i, j)
```

### 시간 복잡도

**O(N)**

`i`에 대한 반복문만 필요하므로 방법 1보다 효율적이다.

---

## 배운 점

완전탐색은 가능한 모든 경우를 직접 확인하기 때문에 구현이 간단하지만, 탐색해야 하는 범위가 커지면 연산 횟수가 빠르게 증가한다.

문제의 조건을 식으로 표현할 수 있다면 불필요한 탐색을 제거하여 더 효율적인 알고리즘을 만들 수 있다.

**O(N²) → O(N)으로 개선**
