# 5명 중 2명 선택

## 문제

학생 5명 중에서 2명을 선택하는 모든 경우를 출력한다.

* 선택 순서는 고려하지 않는다.
* 같은 학생을 중복해서 선택하지 않는다.

---

## 풀이

두 개의 반복문을 사용하여 가능한 모든 조합을 확인한다.

```python
for i in range(1, 6):
    for j in range(i + 1, 6):
        print(i, j)
```

### 핵심 아이디어

두 번째 학생 `j`를 선택할 때 `i + 1`부터 시작한다.

```python
for j in range(i + 1, 6):
```

이를 통해 다음 두 가지 경우를 제외할 수 있다.

* **중복 선택 방지:** `(1, 1)`, `(2, 2)`처럼 같은 학생을 두 번 선택하지 않는다.
* **순서만 다른 조합 제거:** `(1, 2)`를 선택했다면 `(2, 1)`은 다시 선택하지 않는다.

따라서 각 조합을 한 번씩만 확인할 수 있다.

---

## 출력 결과

```text
1 2
1 3
1 4
1 5
2 3
2 4
2 5
3 4
3 5
4 5
```

총 **10가지 조합**이 만들어진다.

---

## 시간 복잡도

학생 수를 `N`이라고 하면 두 명을 선택하는 조합의 수는

`N × (N - 1) / 2`

이므로 시간 복잡도는 **O(N²)**이다.

---

## 배운 점

완전탐색에서 이중 반복문을 사용할 때 두 번째 반복문의 시작점을 조절하면 불필요한 중복 탐색을 제거할 수 있다.

특히 `j = i + 1`부터 탐색하는 방식으로 **순서를 고려하지 않고 중복 없이 두 개를 선택하는 조합**을 구현할 수 있다.
