# 3자리 비밀번호 만들기

## 문제

비밀번호가 3자리이고, 각 자리에는 `0~9`의 숫자가 들어갈 수 있을 때 가능한 모든 비밀번호를 출력한다.

* 숫자의 순서를 고려한다.
* 같은 숫자를 중복해서 사용할 수 있다.
* `000`부터 `999`까지 모든 경우를 확인한다.

---

## 풀이

각 자리에서 `0~9` 중 하나를 선택해야 하므로 3개의 반복문을 사용한다.

```python
for i in range(10):
    for j in range(10):
        for k in range(10):
            print(i, j, k)
```

### 핵심 아이디어

첫 번째, 두 번째, 세 번째 자리에서 각각 `0~9`의 숫자를 독립적으로 선택한다.

예를 들어 다음과 같은 경우가 모두 가능하다.

```text
0 0 0
0 0 1
0 0 2
...
1 1 1
...
9 9 9
```

`(1, 2, 3)`과 `(3, 2, 1)`은 순서가 다르므로 서로 다른 비밀번호이며, `(1, 1, 1)`처럼 같은 숫자를 여러 번 사용하는 것도 가능하다.

---

## 경우의 수

각 자리마다 10개의 숫자를 선택할 수 있으므로

`10 × 10 × 10 = 1,000`

총 **1,000가지**의 비밀번호가 만들어진다.

---

## 시간 복잡도

3개의 반복문을 중첩하여 사용한다.

각 자리에서 선택할 수 있는 숫자의 개수를 `N`이라고 하면 시간 복잡도는 **O(N³)**이다.

현재 문제에서는 `N = 10`이므로 총 1,000번의 경우를 확인한다.

---

## 배운 점

중첩 반복문을 이용하면 여러 자리에서 가능한 모든 경우를 직접 생성할 수 있다.

각 선택에서 **순서를 구분하고 중복을 허용하는 경우**, 이전에 선택한 값과 관계없이 모든 범위를 다시 탐색하면 된다.
